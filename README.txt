Практическая работа 1.1, вариант 1.

Структура:
src/                 исходный код модулей
logs/                логи ошибок и контроля качества
data/YYYY-MM-DD/     результат CSV с партиционированием по дате
data/quarantine/     невалидные данные
config.yaml          конфигурация
main.py              запуск парсера
requirements.txt     зависимости

Запуск:
1. pip install -r requirements.txt
2. python main.py

Важно:
В CSV уже помещен результат на 20 первых позиций, собранных с первой и второй
страницы категории "Фирменные роллы" сайта SushkiLove при подготовке работы.
При обычном запуске main.py данные будут собираться непосредственно с сайта.
